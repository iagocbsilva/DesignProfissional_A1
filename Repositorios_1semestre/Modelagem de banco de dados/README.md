A Modelagem de Banco de Dados é o processo de projetar a estrutura de um banco de dados, visando a organização, clareza e eficiência na gestão dos dados.

Principais Propósitos

- Organização e Clareza: Estrutura os dados de forma lógica, eliminando redundâncias.

- Consistência e Integridade: Garante que os dados sejam precisos e consistentes, definindo regras (como chaves primárias).

- Eficiência: Otimiza a estrutura para que a recuperação e o armazenamento de dados sejam rápidos e performáticos.

- Comunicação: Serve como um projeto visual que alinha a compreensão entre analistas, usuários e desenvolvedores. 

- Tecnologias e Abordagens Utilizadas

 **A modelagem é feita em três níveis, usando modelos conceituais específicos e ferramentas de software:**

Modelo Conceitual: Foca no alto nível, descrevendo as "coisas" importantes (entidades) e como elas se relacionam, sem focar em detalhes técnicos.

Tecnologia: Modelo Entidade-Relacionamento (ER). Usa entidades (retângulos), atributos (características) e relacionamentos (losangos) para criar um diagrama que mapeia as necessidades do negócio.

Modelo Lógico: É a evolução do modelo conceitual, adicionando mais detalhes sobre os atributos de dados (como tipos e comprimentos).

Tecnologia: Modelo Relacional (o mais comum), que representa os dados em tabelas (em vez de entidades) e campos (em vez de atributos). É o modelo base para todos os bancos de dados SQL.

Modelo Físico: Especifica os requisitos técnicos do sistema e a forma exata como o banco será construído em um SGBD específico, como tipos de dados, índices e restrições.
