# Desenvolvimento Front-End para web

A disciplina de Desenvolvimento Front-End para Web ensina o básico necessário para criar páginas e interfaces que funcionam direto no navegador. É aqui que a gente aprende como transformar ideias em sites reais, usando as três tecnologias principais do front-end: HTML, CSS e JavaScript.

 # O que a disciplina aborda?

- HTML – Estrutura

- O HTML é onde tudo começa.
Na disciplina, aprendemos a:

- Criar páginas do zero

- Usar tags corretas (semântica)

- Montar títulos, parágrafos, listas, imagens, botões, formulários

- Organizar o conteúdo de maneira lógica

- HTML é o esqueleto do site.

# CSS – Aparência

- O CSS cuida da parte visual do site.
 
- Cores, fontes, espaçamento e estilo

- Criar layouts usando Flexbox e Grid

- Deixar páginas responsivas para celular e computador

- Fazer pequenas animações e efeitos

- CSS é o que deixa a página bonita e organizada.

# JavaScript – Interatividade

- JavaScript é o que faz o site ganhar vida.

- Criar funções e eventos

- Manipular elementos da página (DOM)

- Fazer validação de formulários

- Adicionar interações, menus, alertas e lógica

JS é o cérebro do front-end.

 # Ferramentas e conceitos usados

Durante a disciplina, também são apresentados:

- VS Code e extensões úteis

- Inspecionar Elemento (F12) para testar e ajustar o código

- Conceitos de acessibilidade, responsividade e boas práticas

# Objetivo da disciplina

O objetivo principal é ensinar o aluno a:

Criar páginas completas e funcionais

Entender como HTML, CSS e JS trabalham juntos

Resolver problemas comuns de interface

Estruturar, estilizar e dar vida a um site

Ter base sólida para avançar para frameworks como React e Vue
