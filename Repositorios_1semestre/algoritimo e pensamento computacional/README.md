 **Algoritmos e Pensamento Computacional**
 
- Este repositório documenta os trabalhos da disciplina de Algoritmos e Pensamento Computacional e serve como um dos 4 repositórios exigidos para a A1 de Design Profissional.
  
- A disciplina foca no desenvolvimento da lógica de programação e na capacidade de transformar problemas em soluções algorítmicas eficientes, usando o raciocínio para criar instruções claras e executáveis por um computador.
  
**Objetivos**
 
- Os principais objetivos dos projetos e exercícios neste repositório são:
- Dominar Estruturas de Controle: Utilizar corretamente condicionais (if/else) e laços de repetição (for, while).
- Manipulação de Dados: Implementar e trabalhar com estruturas de dados básicas, como vetores (arrays).
- Desenvolvimento Modular: Escrever programas organizados usando funções e procedimentos.

**Tecnologias Utilizadas**
- PrincipalLinguagem: C
- Implementação dos algoritmos.
- Ferramenta:VS Code e GDB online
