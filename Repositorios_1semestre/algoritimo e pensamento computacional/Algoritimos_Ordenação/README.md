# Algoritmos de Ordenação
Este repositório contém a implementação em C dos algoritmos de ordenação Selection Sort, Merge Sort e Quick Sort, desenvolvida como parte das atividades da disciplina de Algoritmos e Pensamento Computacional e como entregável para a Avaliação A1 de Design Profissional.


- O código tem como objetivo principal não apenas implementar os algoritmos de ordenação, mas também analisar sua eficiência em termos de tempo de execução e número de operações elementares (comparações e movimentações).

O programa inclui uma função de teste (rodarTeste) que permite:

Entrada com RGM: Utilizar os dígitos do número RGM como entrada para o vetor.

Entrada Aleatória: Gerar um vetor aleatório de um tamanho (N) especificado pelo usuário.

Medição: Contabilizar o número de passos (cont) e o tempo de execução (em milissegundos) para cada algoritmo.

Relatório CSV: Gerar uma linha de saída no formato CSV (metodo,N,caso,passos,tempo_ms) para facilitar a coleta de dados e a comparação de desempenho.

 **Objetivos**
Demonstrar a Implementação: Codificar de forma correta e funcional os algoritmos Selection Sort, Merge Sort e Quick Sort.

Análise de Desempenho: Realizar uma análise empírica da complexidade temporal dos algoritmos, medindo o número de comparações (C_CMP) e movimentações (C_MOV) e o tempo de processamento.

Organização Digital: Estruturar o código com funções modulares e um menu de testes claro, demonstrando boas práticas de programação.

Entrega A1: Atender ao requisito da A1 de organizar projetos relevantes, documentando-os com o README apropriado.

**Tecnologias Utilizadas**

Linguagem Principal: C

Compilador: GCC (GNU Compiler Collection)

- Bibliotecas Padrão:

- stdio.h: Entrada/Saída padrão.

- stdlib.h: Funções utilitárias (como malloc e rand).

- string.h: Manipulação de strings (para o RGM).

- time.h: Medição do tempo de execução (clock()).
